# Reports

This directory contains reproducible analytical outputs generated by the DVC
pipeline.

Run:

```bash
dvc repro
```

Expected outputs:

- `reports/eda/eda_report.txt` - EDA summary, missing value assessment, correlations, and guiding-question results.
- `reports/eda/*.png` - EDA visualizations for distributions, box plots, and feature relationships.
- `reports/hypothesis_tests.txt` - Statistical test report generated from the versioned insurance dataset.

The report files are generated artifacts and are intentionally ignored by Git;
their reproducible state is captured in `dvc.lock`.
